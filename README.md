Inspira 

Plataforma que conecta estudantes universitários a profissionais e empresários de destaque para mentorias práticas e orientação de carreira.

O que o projeto faz
Tela de login e cadastro de usuários
Cadastro com nome, universidade, curso, e-mail e WhatsApp
Verificação de conta por código enviado via WhatsApp
Recuperação de senha por e-mail
Tecnologias usadas
HTML
CSS
JavaScript
